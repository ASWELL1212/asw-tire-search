GitHub更新手順
1. リポジトリで Add file → Upload files
2. このフォルダ内の全ファイルをアップロード
3. 既存ファイルの上書きを確認
4. Commit changes
5. 公開アプリを開き、必要なら再読み込み
6. Firebase登録済みメールアドレスとパスワードでログイン
7. 最初の1回だけ「初期データを登録」を押す
